# Third-party strategy notices

This private project implements trading logic derived from public strategy material published by HermanTrading / @RHerman.

- Trend Rebalance Map [Herman]: https://github.com/HermanTrading/Trend-Rebalance-Map-Herman-
- Streak Failure Reversal [Herman]: https://github.com/HermanTrading/Streak-Failure-Reversal-Herman-

The project uses its own labels “1.0” and “1.1” only to distinguish the two integrated strategy engines. Those labels are not claims about the upstream authors' version numbering.

The Streak Failure Reversal upstream file is referenced by URL rather than redistributed verbatim in this private repository.
